## [Science 披露中国未经批准的基因治疗试验致女童死亡](https://www.science.org/content/article/exclusive-death-girl-chinese-gene-editing-trial-was-never-made-public) ⭐️ 10.0/10

《Science》杂志独家调查披露，一名 6 岁女童 2025 年 3 月在上海新华医院接受碱基编辑基因治疗后死亡，该试验绕过国家监管审批，且死亡事件从未公开。 此事件揭露了中国基因编辑临床研究中严重的科学不端行为、监管规避和缺乏透明度，可能损害全球对基因治疗安全性和伦理监督的信任。 女童患有一种罕见的单碱基突变遗传病；研究团队通过脊髓液注射了数万亿 AAV 病毒载体以靶向脑部神经元，7 天后她因严重免疫反应死亡。研究负责人神经科学家仇子龙利用“医院豁免”绕过国家审批，且 2026 年发表的动物实验论文未提及人体试验。

telegram · zaihuapd · 7月24日 05:18

**背景**: 碱基编辑是一种源自 CRISPR 的技术，可以精确修改单个 DNA 碱基。AAV 病毒载体（腺相关病毒）常用于基因治疗递送，但高剂量可能引发免疫反应。在中国，临床试验需要严格的国家审批；“医院豁免”通常仅适用于紧急情况或已上市产品，不能用于未经批准的研究性治疗。

## [安全摄像头出厂内置 GitHub 管理员令牌](https://hhh.hn/hanwha-github-token/) ⭐️ 9.0/10

一款商用安全摄像头被发现在其登录页面中内置了硬编码的 GitHub 管理员令牌，任何发现该令牌的人都可以访问供应商的 GitHub 仓库。 这一事件凸显了物联网设备中的严重安全缺陷，硬编码凭据可能导致供应链攻击、代码篡改以及更广泛的系统入侵。 该硬编码令牌出现在摄像头的登录页面 HTML 中，是一个具有管理员权限的 GitHub 个人访问令牌，暴露了供应商的整个代码库。

**背景**: 硬编码凭据是固定在设备固件中的密码或令牌，攻击者可通过逆向工程提取。GitHub 个人访问令牌可授权 API 访问仓库；管理员令牌能修改代码、工作流和密钥。由于开发仓促且缺乏安全审计，此类漏洞在物联网设备中屡见不鲜。
