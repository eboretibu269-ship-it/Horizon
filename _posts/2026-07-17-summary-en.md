## [Rust-to-Zig Compiler Rewrite Progress Report](https://rtfeldman.com/rust-to-zig) ⭐️ 8.0/10

The author is rewriting a compiler originally built in Rust into Zig, citing reasons such as better incremental build times and more flexible memory management. The blog post details the progress and rationale behind the language switch. This rewrite highlights important trade-offs in systems programming languages, especially for compilers where performance and memory control are critical. It fuels the ongoing debate between Rust's compile-time safety and Zig's more pragmatic runtime safety approach. The rewrite focuses on achieving faster incremental builds and improved cross-compilation. Unlike Rust's strict ownership model, Zig provides memory safety through runtime checks in debug and release safe modes, which the author considers more suitable for certain compiler tasks like binary patching.

hackernews · jorangreef · Jul 16, 11:39 · [Discussion](https://news.ycombinator.com/item?id=48933149)

**Background**: Rust enforces memory safety at compile time via its ownership and borrowing rules, preventing use-after-free and data races. Zig, in contrast, offers more low-level control with optional runtime safety checks, making it appealing for projects that need flexibility. Compilers often perform unsafe operations like emitting machine code or hot patching, which can be cumbersome under Rust's strict model.

## [ExTernD: Ternary LLM PTQ with Nearly Any Accuracy](https://www.reddit.com/r/MachineLearning/comments/1uy2zb3/externd_expandedrank_ternary_decomposition/) ⭐️ 8.0/10

ExTernD introduces expanded-rank ternary decomposition for post-training quantization of LLM weight matrices, decomposing each matrix into two ternary matrices and a diagonal scaling matrix to allow arbitrary accuracy with only a modest VRAM increase. This method challenges the previous belief that ternary PTQ is a dead end due to fixed matrix size, offering accuracy approaching any quantization level while maintaining efficiency, potentially enabling highly compressed LLM inference with minimal accuracy loss. The decomposition uses two ternary matrices and an inner diagonal scaling matrix, where the inner rank can be arbitrarily large to control accuracy. The author claims that the VRAM increase over current quantization methods is slight and justified by exploiting ternary math.

reddit · r/MachineLearning · /u/LMTLS5 · Jul 16, 13:31

**Background**: Post-training quantization (PTQ) reduces LLM memory footprint by compressing weight matrices to low-bit representations like ternary (values -1, 0, +1). Traditional ternary quantization forces a fixed matrix size, limiting accuracy. ExTernD overcomes this by decomposing the matrix into a product of low-rank ternary factors.
