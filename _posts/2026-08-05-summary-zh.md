## [杰夫·迪恩创立 Discovery Loop，旨在自动化科学实验循环](https://www.discoveryloop.com/) ⭐️ 9.0/10

## [ChainDrop 蠕虫攻陷 npm 超过 1300 个软件包](https://www.bleepingcomputer.com/news/security/massive-chaindrop-npm-supply-chain-attack-infects-hundreds-of-packages/) ⭐️ 9.0/10

自我传播的 ChainDrop 蠕虫已攻陷超过 1300 个 npm 软件包，包括流行的缓存库 Keyv 和 Cacheable，合计月下载量达 20 亿次。攻击始于攻破维护者的 GitHub 账号，且目前仍在扩散。 这是迄今规模最大的 npm 供应链攻击之一，波及下载量达数十亿次的软件包，并瞄准开发者在 GitHub、npm、AWS 和 Kubernetes 等平台的凭证。该蠕虫具有自我传播特性，预计受感染软件包数量还会增加，对整个开源生态构成重大威胁。 恶意软件包携带 setup.mjs 投放器，会在执行 `npm install` 时运行 727 KB 的窃密脚本 Math_Symbol.js，窃取令牌并植入持久化后门。安全研究人员建议，只要安装过受影响版本的系统都应视为已被攻破，并立即轮换所有凭证；域名 npm-cache[.]com 可作为失陷指标。

telegram · zaihuapd · 8月5日 03:04

**背景**: npm 是 Node.js 的默认包管理器，也是全球最大的软件注册表之一，拥有数百万个软件包，广泛用于 JavaScript 生态系统。供应链攻击通过攻破维护者账号或构建流程，使恶意代码在用户安装可信软件包时被自动投递。ChainDrop 是一种蠕虫，它利用被窃取的 npm 凭证感染其他维护者的软件包，像链条一样不断扩大攻击范围。

## [Neon 的 Castform 以百倍低成本在检索上击败 GPT-5.6 Sol](https://neon.com/blog/how-castform-neon-beats-frontier-models-on-price-and-efficiency) ⭐️ 8.0/10
